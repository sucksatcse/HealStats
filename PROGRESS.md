## 3. Authentication & Authorization (Task 25 & Task 25.1 Hardened)
- **Supabase Client**: Initialized in `frontend/src/lib/supabase.ts`.
- **Real Supabase Auth**: All login flows (`LoginPage.tsx`, `AdminLoginPage.tsx`) authenticate against Supabase Auth (`supabase.auth.signInWithPassword`). Hardcoded demo credential bypasses, synthetic sessions, and fake user IDs have been completely removed from application code.
- **Public Signup Hardening**: `SignUpPage.tsx` restricts self-registration strictly to healthcare worker clinical designations (`community_health_worker`, `nurse`, `clinical_officer`) and hardcodes `role: "worker"` in the database payload. District administrator and patient signup options have been eliminated.
- **Global Context**: `AuthContext.tsx` handles real session restoration, user state, and `staff` profile lookup (`staff.auth_user_id`). Exposes `profileResolved` so a session with no linked staff row is distinguishable from a still-loading profile.
- **Protected Routing**: Implemented directly in `App.tsx`. Unauthorized users are bounced to the appropriate login screen. Admin routes are locked behind `role === 'admin'`. Non-admins authenticating at `AdminLoginPage` are rejected and signed out. Render-time guards prevent any flash of protected content before redirect resolves, and a valid session with no staff profile shows an "Account not linked" escape screen.
- **Login Pages**: 
  - `LoginPage.tsx` (For standard health workers, real Supabase Auth)
  - `AdminLoginPage.tsx` (For clinic administrators, verifies real `staff.role === 'admin'`)
- **Authentication-Aware Navbar & Logout**:
  - `AppNavbar.tsx` dynamically detects `session` state from `AuthContext`.
  - For unauthenticated/guest visitors, the broken user avatar and inert "Log Out" popover are completely removed, replaced by production-style bilingual **Log In** (`লগ ইন`) and **Sign Up** (`সাইন আপ`) CTA buttons.
  - Mobile drawer provides full-width `Log In` and `Sign Up` buttons for small screens.
  - Authenticated sessions display user profile avatar, name, role, quick-access Dashboard navigation, and a functional **Log Out** button that executes `await signOut()`, clears state, and resets to landing view.
  - Sidebar logout buttons in `DashboardPage.tsx` and `AdminDashboardPage.tsx` are wired to real `signOut()` handling.
